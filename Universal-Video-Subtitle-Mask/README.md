# Universal Video Subtitle Mask

通用视频字幕遮罩 —— 一个零权限的 Chrome 扩展，用来遮挡视频画面中「烤入」（硬编码）的字幕文字。

典型场景：

- **英语学习**：盖住中文字幕，只保留英文，逼自己靠听力理解
- **外语影视**：遮掉翻译字幕，避免视线被字幕带走
- 任何想遮住画面内固定文字的场景

## 支持站点

Bilibili、YouTube、Netflix、TED、Coursera（如需增减，直接改 `manifest.json` 中 content_scripts 的 `matches` 即可）

## 安装

1. 打开 Chrome，地址栏输入 `chrome://extensions` 回车
2. 右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本文件夹
4. 打开任一支持站点并播放视频，遮罩会自动出现（页面检测到 `<video>` 后挂载）

## 使用

- **拖拽**遮罩条移动位置；拖右 / 下 / 右下角手柄三向缩放
- **双击**遮罩弹出调节条：宽度、高度、透明度、水平居中
- 右侧**悬浮胶囊**：⊘ 开关遮罩 · 🎨 切换主题 · 取色器自定义颜色 · 中 / 英界面切换 · ❯ 收纳入屏幕边缘（悬停临时滑出）
- 遮罩默认出现在画面底部约 84% 高度处，可根据字幕位置拖到任意位置

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `C` | 切换主题 |
| `Alt+H` / `Ctrl+Shift+H` | 收起 / 展开胶囊 |
| `Alt+[` / `Alt+]` | 缩窄 / 加宽 |
| `Alt+-` / `Alt+=` | 变矮 / 增高 |
| `Alt+0` | 水平居中 |
| `Alt+M` / `Ctrl+Shift+X` | 显示 / 隐藏遮罩 |

> 焦点位于输入框 / 文本域时快捷键自动失效，避免误触。

## 说明

- Manifest V3，无需任何权限，代码全部本地运行
- 界面语言偏好会记住（localStorage）；遮罩的位置 / 尺寸 / 主题 / 透明度暂不持久化，刷新页面后重置
